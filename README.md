# 藤原整体院 予約状況カレンダー

LINE から開く患者さん向けの「空き状況」ページと、院長専用の管理画面です。

- 日付は日本時間の今日から30日先までを毎日自動で表示します。月末の作業はありません。
- 何も入力しない日は ○（予約可能）になります。変更がある日だけ管理画面でタップします。
- 管理画面には匿名のアクセス状況（閲覧数・推定訪問者数・LINE経由）も表示します。
- 維持費は0円です（Google Apps Script ＋ スプレッドシート ＋ 無料の静的ホスティング）。

## 構成

```
public/            公開ページ（GitHub Pages などに置く）
  index.html       カレンダー本体（API_URL 未設定のときはデモ表示）
  dates.js         日付計算（日本時間）
gas/               Google Apps Script（スプレッドシートに紐づける）
  Code.gs          公開用API・保存・アクセス集計
  admin.html       管理画面（予約状況／アクセス状況）
  appsscript.json  設定（タイムゾーン Asia/Tokyo）
tests/             node tests/dates.test.js ／ node tests/gas.test.js
design/            STEP 1 のデザイン案
```

スプレッドシートは内部データ置き場です。患者さんには公開しません。保存するのは次の2つだけで、個人情報は保存しません。

- シート「予約状況」：○以外の日の「日付・状態」
- シート「アクセス」：日別の閲覧数・推定訪問者数

## 公開までの手順

### 1. スプレッドシートと Apps Script を用意する

1. 院長の Google アカウントで、新しいスプレッドシートを作ります（名前は例：「予約カレンダー データ」）。共有はしません。
2. メニューの「拡張機能 → Apps Script」を開きます。
3. `Code.gs` の中身を `gas/Code.gs` の内容に置き換えます。
4. 「＋ → HTML」で `admin` という名前のファイルを作り、`gas/admin.html` の内容を貼り付けます。
5. 「プロジェクトの設定」で「appsscript.json を表示」をオンにし、`gas/appsscript.json` の内容に置き換えます。
6. 関数 `setup` を選んで「実行」します。権限の確認が出たら許可してください。シート2枚と毎日深夜の掃除が設定されます。

### 2. 2種類のウェブアプリとして公開する

同じスクリプトを2回デプロイします。

| 用途 | 次のユーザーとして実行 | アクセスできるユーザー |
|---|---|---|
| 公開用（患者さんのページが読む） | 自分 | **全員** |
| 管理用（院長だけ） | 自分 | **自分のみ** |

「デプロイ → 新しいデプロイ → 種類：ウェブアプリ」で、上の表のとおり2つ作ります。

- 公開用の URL（`…/exec`）は `public/index.html` の `API_URL` に入れます。
- 管理画面は、管理用の URL の末尾に `?page=admin` を付けて開きます。スマートフォンのホーム画面に追加しておくと便利です。院長の Google アカウントでログインしていないと開けません。

> 公開用の URL に `?page=admin` を付けても、院長以外には「表示できません」と出ます。保存とアクセス状況の取得も、院長のアカウント以外では拒否されます。

### 3. 公開ページを置く

`public/` フォルダの中身を GitHub Pages など無料の静的ホスティングに置きます。公開されたページの URL を `gas/Code.gs` の `PUBLIC_PAGE_URL` に入れると、管理画面に「公開ページを見る」リンクが出ます。

### 4. LINE のリンクを差し替える

LINE 公式アカウントのリンクを、新しいページの URL の末尾に `?from=line` を付けたものに変更します（例：`https://…/index.html?from=line`）。LINE 内ブラウザは自動で判別しますが、付けておくと LINE 経由の数がより正確になります。

旧スプレッドシートのカレンダーは、移行を確認し終わるまで残しておいてください。

### 5. 院長ご自身の閲覧を集計から外す（任意）

ご自分のスマートフォンで、公開ページの URL の末尾に `?notrack=1` を付けて一度開きます。以後その端末の閲覧は数えません（`?notrack=0` で元に戻ります）。

## 更新するとき

Apps Script のコードを変えたら「デプロイを管理 → 編集 → バージョン：新バージョン」で、公開用と管理用の両方を更新します。URL は変わりません。

## アクセス集計のしくみ

- ページを開くと、表示が終わった後に「閲覧1回」を送ります。カレンダーの表示は待たせません。
- 端末には「最後に数えた日・月・時刻」だけを保存します。識別子は送らず、サーバーは日別の数を足すだけです。
- 同じ端末で10分以内に開き直した分は閲覧数に含めません。
- 訪問者数は「その日・その月にその端末で初めて開いた回数」の合計で、推定値です。
